# Parcours francais : op-viem (extension viem pour les chaines OP Stack de Base)

Lecture pedagogique du depot base/op-viem : l extension viem (deprecated, remplacee par le support natif viem/op-stack) pour les operations de pont entre Ethereum L1 et les chaines OP Stack (Base, Optimism, Zora).

Sommaire :

Chapitre 1 Presentation de op-viem. Chapitre 2 Les quatre decorateurs, etendre un client viem. Chapitre 3 Le flux de depot, d Ethereum vers la chaine OP Stack. Chapitre 4 Le flux de retrait, trois etapes obligatoires. Chapitre 5 Adresses de contrats, predeployes L2 et deploiements L1. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
